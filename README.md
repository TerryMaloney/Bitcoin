# Bitcoin

A small, transparent Bitcoin research, paper-trading, and decision-support project.

## Purpose

This repository is the source of truth for a deliberately small Bitcoin experiment. It is intended to:

- research and test Bitcoin-specific market signals;
- run reproducible backtests and paper trading;
- fetch independent BTC/USD and market-structure data;
- evaluate pre-defined decision rules;
- support notifications without automatically trading real funds.

## Safety boundary

This project does **not** place real trades, hold PayPal credentials, or make autonomous live buy/sell decisions. Real holdings and account-specific details should not be committed to this public repository.
